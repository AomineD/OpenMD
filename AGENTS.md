# Agent Instructions — OpenMD

## Plan Files

When asked to plan, research, or create a technical specification:

1. **Save the plan to `.plans/` in the project root** — never output it as a chat message
2. **Naming**: `.plans/YYYY-MM-DD_<topic-slug>.md`
   Example: `.plans/2026-03-30_viewer-performance.md`
3. **Create the directory if it doesn't exist** before writing
4. **After saving**, open it in OpenMD:
   `openmd "<absolute-path-to-plan-file>"`
